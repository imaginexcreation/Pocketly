# ImagineX Creations website

Static site for GitHub Pages, custom domain imaginexcreation.com.

## Files
- index.html, style.css, script.js: home page (studio, FarmPilot, Dokaner Hisab, Hill Climb)
- about.html, about.css, about.js: about and contact page (also used by privacy.html and 404.html)
- privacy.html, 404.html, robots.txt, sitemap.xml, site.webmanifest
- logo.png, og-image.png, favicon.png, icon-192.png, icon-512.png
- CNAME (custom domain), .nojekyll

## Things to edit
- Email: search for hello@imaginexcreation.com in index.html, about.html, about.js, privacy.html
- Facebook link: search for facebook.com/profile.php
- Language texts: every text has a data-bn attribute (Bangla) and English inside the tag
- Colors: the variables at the top of style.css and about.css
